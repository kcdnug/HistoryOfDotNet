# Style Guide

## Visual style

- Dark background.
- Large titles.
- Minimal text per slide.
- Code should be the visual centerpiece when possible.
- Use side-by-side “Old way / New default” slides for major shifts.
- Use the phrase “What became normal?” as a recurring motif.

## Code sample rules

- Prefer short, memorable samples over complete production examples.
- Samples should be realistic enough to feel familiar.
- Use comments sparingly.
- Avoid clever code that requires too much explanation.
- Keep before/after samples visually balanced.

## Speaker notes

Every slide should include an HTML comment with notes. Suggested shape:

```html
<!--
Speaker notes:
- Purpose: ...
- Emphasize: ...
- Transition: ...
-->
```

## Editing rules for AI agents

- Do not remove speaker notes.
- Do not turn this into a comprehensive release history.
- Keep the core question visible throughout: “What did this make normal?”
- Preserve the “old code was not bad code” framing.
- Mark preview/future features clearly.
