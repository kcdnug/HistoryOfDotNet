# Original Title and Abstract

## Title

**The Code We Don't Write Anymore**

## Subtitle

**How .NET Changed the Way We Think About Code**

## Abstract

Every .NET release changes what’s possible, but only some of them change what we actually write. This talk walks the timeline from Framework 1.0 to .NET 11 and asks a single question of each release: what did it make normal? Generics ended the cast-and-pray era. LINQ made us think in sequences instead of loops. async/await rewrote every I/O path we own. Nullable reference types forced us to admit what we’d been assuming. Minimal APIs, source generators, and native AOT quietly moved work from runtime to build time. We’ll trace those shifts, look at where the language pushed us and where it followed us, and end on what C# 15’s union types suggest about where we’re heading next.
