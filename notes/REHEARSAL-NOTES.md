# Rehearsal Notes

## Opening

Start with empathy: “None of this old code was bad code. It was what good code looked like when those were the tools.”

## Anchor phrases

- “What did this make normal?”
- “We stopped writing that because the platform made the better thing easy.”
- “The compiler became a collaborator.”
- “This is a history of defaults.”

## Places to slow down

- Generics: first major change in everyday code.
- LINQ: thinking in sequences instead of loops.
- async/await: architecture changed, not just syntax.
- Nullable reference types: types became contracts.
- Source generators / AOT: runtime work moved to build time.
- Union types: future-facing direction toward explicit state.
